# 11. Dashboard

The Dashboard is the main page after login.

Its purpose is to provide a quick overview of the user's day.

The dashboard should answer:

> What do I need to do today?
> How am I progressing?
> What should I pay attention to?

### Recommended sections

#### Header

- Greeting
- Current streak
- Today's XP

#### Today's Tasks

- Upcoming task
- Completed task
- Task status
- Priority

#### Today's Habits

- Habit list
- Check-in action
- Current streak

#### Goals

- Active goals
- Progress
- Deadline/status

#### Ranking

- Current weekly rank
- XP this week

#### Daily Fortune

A small entertainment widget.

#### Optional widgets

- Calorie status
- Focus timer
- Daily progress percentage

The Dashboard should be customizable later, but V1 can use a fixed layout.
